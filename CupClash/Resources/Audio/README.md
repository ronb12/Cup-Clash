# Cup Clash audio filenames

Audio is optional. `AudioManager` fails safely when a file is missing.

Place CAF, WAV, or MP3 files in this folder (or the app bundle) using these names:

| Event | Filename |
| --- | --- |
| Button tap | `sfx_button` |
| Ball throw | `sfx_throw` |
| Table bounce | `sfx_table` |
| Cup rim hit | `sfx_rim` |
| Made shot | `sfx_made` |
| Miss | `sfx_miss` |
| Turn change | `sfx_turn` |
| Victory | `sfx_victory` |
| Defeat | `sfx_defeat` |
| Coin reward | `sfx_coins` |
| Level up | `sfx_levelup` |
| Ambient music | `music_ambient` |

Do not add copyrighted commercial music.
