# Cup Clash: Pong Rivals

Family-friendly 3D arcade cup-toss for iPhone. Swift, SwiftUI, RealityKit, GameKit, and SwiftData.

Created by Ronell Bradley. Property of Bradley Virtual Solutions, LLC.

## Requirements

- Xcode 16 or later
- iOS 17.0+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen)

## Open and run

```bash
cd "Cup Clash"
xcodegen generate
open CupClash.xcodeproj
```

Select the **CupClash** scheme and an iPhone simulator, then Run.

## Modes

- Quick Match against Rookie, Pro, or Champion AI
- Pass & Play on one device
- Practice with unlimited throws

Audio files are optional. See `CupClash/Resources/Audio/README.md`. App icon artwork: `APP_ICON.md`.
